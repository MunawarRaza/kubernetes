Replication Controller
To launch more pods we use replication controller. We define our desired state. Replication Controller make sure to fulfill our desired states.
ReplicaSet:
It is the advancement of replication controller. In this we define the matchLables field. E.g if we already have 1 pod whos lable is same as we defined in the manifist of ReplicaSet, ReplicaSet start manageing that pod as well.
Deployments:
It is the advancement of ReplicaSet because it provide more advanced features such as rolling updates, rollbacks and Versioning Control. 
StatefullSets:
StatefulSet is the controller that manages the deployment and scaling of a set of Stateful pods. A stateful pod in Kubernetes is a pod that requires persistent storage and a stable network identity to maintain its state all the time, even during pod restarts or rescheduling
DaemonSet:
A DaemonSet ensures that a single instance of a pod is running on each node in a cluster.
