 Cgroup is the kernel feature that allow processes to be organized into hierarchical groups with specific resource constraints.

What are Cgroup Drivers?
To interact with cgroup, cgroup driver is used.

Types of Cgroup Drivers
    cgroupfs
    systemd

Cgroupfs is the default cgroup driver in the kubelet. 

systemd cgroup driver: when systemd is the init system for linux distribution then it is recommended to use systemd cgroup dirver.

How to check systemd is init system or not?

1- ps -p 1 -o comm= ( if output is systemd then systemd is the init system)
2- cat /proc/1/comm ( if output is systemd then systemd is the init system)
3- pidof systemd ( if output returns a PID then systemd is the init system)

How to configure cgroup driver in kubelet and containerd?

Configure Cgroup driver as systemd in containerd
    check if SystemdCgroup is present in /etc/containerd/config.toml if present then change SystemdCgroup = false to true
    if not present then do the following things
    mv /etc/containerd/config.toml /opt/
    containerd config default > /etc/containerd/config.toml
    vim /etc/containerd/config.toml
    Replace SystemdCgroup = false to SystemdCgroup = true
    systemctl restart containerd
Configure Cgroup driver as systemd in kubelet configuration.
edit the KubeletConfiguration option of cgroupDriver and set it to systemd
 For example
			apiVersion: kubelet.config.k8s.io/v1beta1
			kind: KubeletConfiguration
			...
			cgroupDriver: systemd
            
    kubelet --feature-gates=SystemdCgroup=true
    Or
    /var/lib/kubelet/config.yaml
    cgroupDriver: systemd
